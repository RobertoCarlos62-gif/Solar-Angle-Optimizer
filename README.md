# ☀️ SolarOptima: Optimizador de Inclinación Panel Solar

Este es un programa de ingeniería desarrollado en Python enfocado en la **sostenibilidad y eficiencia energética**. Su objetivo es resolver las pérdidas por desalineación solar en sistemas fotovoltaicos residenciales e industriales.

## 📋 Problema Real
Los paneles solares fijos pierden un alto porcentaje de radiación debido al cambio de posición del sol a lo largo de las estaciones. Calcular manualmente el ángulo ideal requiere fórmulas astronómicas complejas.

## 🚀 Solución
Este script automatiza el cálculo de la **declinación solar diaria** y determina el ángulo de inclinación óptimo mes a mes para cualquier coordenada del planeta (Hemisferio Norte o Sur), exportando un reporte de ingeniería en formato `.txt`.
